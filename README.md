# 🚌 버스콕검

전세버스 임차 서류 확인을 도와주는 웹앱입니다.

업체가 제출한 PDF·이미지 서류를 업로드하면 배정차량 기준으로 필요한 서류가 있는지, 어느 파일 어느 쪽을 확인해야 하는지, 담당자가 무엇을 직접 확인해야 하는지 정리해줍니다.

> 자동으로 적합/부적합을 최종 판정하는 도구가 아니라, 계약 담당자가 놓치기 쉬운 서류 확인 지점을 정리해주는 검토 보조 도구입니다.

배포 페이지
https://sen-vip.github.io/bus-kockgum/

---

## ✨ 주요 기능

* 출발일 기준 보험기간·검사유효기간 확인
* 배정차량 리스트 자동 추출 및 수동 보정
* PDF·이미지 파일 업로드 후 제출파일 정리
* 실무 검토 순서에 맞춘 필요서류 확인
* 차량별 보험, 등록증, 등록원부, 교통안전정보, 점검표 확인
* 서류별 파일 위치, 확인할 사항, 담당자가 할 일 정리
* 업체 보완요청 문구 자동 생성 및 복사
* 결과표 CSV 내보내기
* 스캔본·이미지 PDF는 위치 후보로 안내
* 브라우저 기반 처리로 파일 내용 외부 전송 없음

---

## 🔎 검토 흐름

버스콕검은 결과 화면을 실무자가 보는 순서에 맞춰 정리합니다.

1. 제출파일 정리
   업로드한 파일이 어떤 서류 후보로 분류되었는지 먼저 확인합니다.

2. 필요서류 확인
   계약조건별 서류, 업체 확인 서류, 차량검토 기준자료, 차량별 필수서류 순서로 확인합니다.

3. 차량별 확인
   배정차량별로 보험, 자동차등록증, 자동차등록원부, 교통안전정보, 출발 전 점검표를 확인합니다.

4. 보완요청
   부족하거나 직접 확인이 필요한 서류에 대해 업체에 보낼 문구를 정리합니다.

---

## 🧭 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 출발일을 입력합니다.
3. 필요하면 도착일, 업체명, 행사명, 계약방식, 추정가격을 입력합니다.
4. 배정차량 관련 파일을 업로드합니다.
5. 배정차량을 추출하고, 잘못 읽힌 차량번호는 직접 수정합니다.
6. 보험, 등록증, 등록원부, 교통안전정보, 점검표 등 제출서류를 업로드합니다.
7. `콕검 실행하기` 버튼을 누릅니다.
8. 결과 화면에서 제출파일 정리, 필요서류 확인, 차량별 확인, 보완요청 순서로 검토합니다.
9. 필요한 경우 `문구 복사` 버튼으로 보완요청 문구를 복사합니다.

## 📁 확인 가능한 서류

계약조건별 서류

* 직접생산확인증명서
* 중소기업확인서 등 계약조건에 따라 필요한 서류

업체 확인 서류

* 사업자등록증
* 여객자동차 운송사업등록증
* 직영차량 운행각서

차량검토 기준자료

* 차량보유 현황표
* 차량운행계획서
* 차량 및 운전기사 배정 현황

차량별 필수서류

* 자동차 종합보험 가입증명서
* 자동차등록증
* 자동차등록원부
* 전세버스 교통안전정보 조회결과 통보서
* 출발 전 교육 및 차량안전점검표

## 🧾 결과 화면 구성

제출파일 정리

업로드한 파일이 어떤 서류 후보로 잡혔는지 먼저 보여줍니다.
파일별로 텍스트 PDF인지, 이미지 PDF인지, 서류 후보가 무엇인지 확인할 수 있습니다.

필요서류 확인

각 서류 항목은 아래 구조로 정리됩니다.

```text
자동차 종합보험 가입증명서 [못 찾음]        [문구 복사] [상세보기]
차량번호 · 계약기간 · 담보내용
파일: 확인된 위치 없음
```

상세보기를 누르면 아래 내용이 펼쳐집니다.

```text
파일 위치
확인할 사항
담당자가 할 일
보완요청 문구
```

차량별 확인

차량별로 보험, 등록증, 등록원부, 교통안전정보, 점검표 상태를 확인합니다.
표 헤더는 고정되어 있어 아래로 내려가도 어떤 항목을 보고 있는지 확인할 수 있습니다.

보완요청

업체에 요청할 보완 문구를 자동으로 정리합니다.
필요한 문구는 복사해서 공문, 메일, 메신저 등에 붙여넣을 수 있습니다.

## 🏷️ 상태값 안내

| 상태             | 의미                                  |
| -------------- | ----------------------------------- |
| 확인완료           | 서류와 핵심값이 비교적 명확하게 확인된 상태            |
| 못 찾음           | 제출파일에서 해당 서류 또는 핵심값을 찾지 못한 상태       |
| PDF 위치 후보      | 해당 PDF 쪽에 있을 가능성이 있어 담당자 확인이 필요한 상태 |
| 원본 확인 필요       | 자동 판독만으로 확정하기 어려워 원본 화면 확인이 필요한 상태  |
| 담당자가 직접 확인해주세요 | 자동으로 판단하기 어려워 담당자가 직접 확인해야 하는 상태    |
| 해당 시 확인        | 계약조건에 따라 제출 필요 여부가 달라지는 상태          |
| 보완필요           | 서류 또는 핵심 확인값이 부족해 업체에 보완 요청이 필요한 상태 |

## 📝 용어 기준

파일 위치

실제 파일명과 쪽수만 표시합니다.

예시:

```text
대청중학교 적격서류.pdf 1~3쪽
확인된 위치 없음
```

확인할 사항

담당자가 해당 서류에서 봐야 하는 체크포인트입니다.

예시:

```text
차량번호 · 계약기간 · 담보내용
업체명 · 사업자등록번호
차량번호 · 검사유효기간
```

담당자가 할 일

현재 상태에서 담당자가 실제로 해야 할 행동입니다.

예시:

```text
계약기간이 이용기간을 포함하는지 확인
해당 PDF 2쪽에서 차량번호와 검사유효기간 확인
업체에 사업자등록증 제출 요청
```

## 🔐 파일 내용 외부 전송 없음

버스콕검은 업로드한 PDF·이미지 파일을 현재 브라우저에서 처리합니다.

파일 내용은 외부 서버로 전송하지 않습니다.

단, PDF 텍스트 추출을 위해 PDF.js 라이브러리를 CDN에서 불러올 수 있고, 사용자가 글자 판독 기능을 실행하는 경우 Tesseract.js 및 언어 모델 파일을 CDN에서 불러올 수 있습니다.

이 과정은 분석 도구를 내려받는 것이며, 사용자가 업로드한 파일 내용이 외부로 전송되는 것은 아닙니다.

## ⚠️ 한계와 주의사항

* 자동 결과는 행정 검토 보조용입니다.
* 최종 확인과 책임은 담당자가 직접 해야 합니다.
* 스캔본, 흐린 이미지, 기울어진 문서, 도장이나 스탬프가 겹친 파일은 정확도가 떨어질 수 있습니다.
* 보험기간, 검사유효기간, 실제 배차 차량, 실제 운전자, 출발 전 점검 여부는 원본 확인이 필요할 수 있습니다.
* 교통안전정보 통보서의 진위 여부는 별도 확인이 필요합니다.
