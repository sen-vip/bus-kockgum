# 🚌 버스콕검 v0.2.28

전세버스 임차 서류를 담당자가 직접 확인할 수 있도록 정리해주는 체크리스트형 웹앱입니다.

자동으로 최종 적합/부적합을 판정하는 도구가 아니라, 업로드한 제출파일을 일부 자동 분류한 뒤 담당자가 직접 확인해야 할 항목을 체크리스트로 정리해주는 검토 보조 도구입니다.

배포 페이지: https://sen-vip.github.io/bus-kockgum/

---

## ✨ 주요 기능

- 출발일 기준 보험기간·검사유효기간 확인 보조
- 배정차량 리스트 자동 추출 및 수동 보정
- 제출파일의 서류 후보 및 관련 페이지 정리
- 필요서류를 실무 검토 순서대로 체크리스트화
- 차량별 보험, 자동차등록증, 자동차등록원부, 교통안전정보, 출발 전 점검표, 운전자 일치 여부 확인
- 담당자가 직접 체크할 수 있는 체크박스 제공
- 부족 서류에 대한 보완요청 문구 복사
- 브라우저 기반 처리로 파일 내용 외부 전송 없음

---

## 🧭 검토 흐름

1. 제출파일 정리  
   업로드한 파일이 어떤 서류 후보로 분류되었는지 참고용으로 확인합니다.

2. 필요서류 체크리스트  
   계약조건별 서류, 업체 확인 서류, 차량검토 기준자료, 차량별 필수서류 순서로 확인합니다.

3. 필요서류 체크리스트 안의 차량별 체크  
   배정차량별로 차량번호와 운전자, 보험, 자동차등록증, 자동차등록원부, 교통안전정보, 출발 전 점검표를 체크합니다.

4. 보완요청  
   부족하거나 직접 확인이 필요한 서류에 대해 업체에 보낼 문구를 정리합니다.

---

## 📁 확인 서류 범위

계약조건별 서류

- 직접생산확인증명서
- 중소기업확인서 등 계약조건에 따라 필요한 서류

업체 확인 서류

- 여객자동차 운송사업등록증
- 사업자등록증
- 직영차량 운행각서

차량검토 기준자료

- 차량보유 현황표
- 차량운행계획서
- 차량 및 운전기사 배정 현황

차량별 필수서류

- 자동차 종합보험 가입증명서
- 자동차등록증
- 자동차등록원부
- 전세버스 교통안전정보 조회결과 통보서
- 출발 전 교육 및 차량안전점검표

## 🏷️ 상태값

| 상태 | 의미 |
|---|---|
| 제출 확인됨 | 제출된 것으로 볼 수 있음 |
| 관련 페이지 있음 | 관련 페이지 후보가 있음 |
| 담당자 확인필요 | 자동판단이 어려워 사람이 확인해야 함 |
| 못 찾음 | 관련 내용을 찾지 못함 |
| 보완 필요 | 제출 또는 확인 보완이 필요함 |

## 🔐 보안 안내

버스콕검은 업로드한 PDF·이미지 파일을 현재 브라우저에서 처리합니다.

파일 내용은 외부 서버로 전송하지 않습니다.

PDF 텍스트 추출이나 이미지 글자 판독을 위해 PDF.js, Tesseract.js 같은 라이브러리를 CDN에서 불러올 수 있지만, 이는 분석 도구를 내려받는 과정이며 사용자가 업로드한 파일 내용이 외부로 전송되는 것은 아닙니다.

## ⚠️ 주의사항

- 자동 결과는 행정 검토 보조용입니다.
- 최종 확인은 담당자가 직접 해야 합니다.
- 스캔본, 흐린 이미지, 기울어진 문서, 도장이나 스탬프가 겹친 파일은 정확도가 떨어질 수 있습니다.
- 보험기간, 검사유효기간, 실제 배차 차량, 실제 운전자, 출발 전 점검 여부는 원본 확인이 필요할 수 있습니다.
- 교통안전정보 통보서의 진위 여부는 별도 확인이 필요합니다.
