# 🚌 버스콕검

전세버스 임차 서류 콕 검토 도구

버스콕검은 추정가격, 계약조건, 제출서류를 기준으로 확인이 필요한 서류와 검토 포인트를 정리해주는 **전세버스 임차 서류 검토 보조 웹앱**입니다.

업체 확인 서류부터 차량별 필수서류까지, 담당자가 놓치기 쉬운 부분을 순서대로 확인할 수 있도록 돕는 실무형 보조 도구입니다.

* 바로가기: https://sen-vip.github.io/bus-kockgum/
* 저장소: https://github.com/sen-vip/bus-kockgum
* 현재 버전: v0.2.42

---

## ✨ 주요 기능

* 전세버스 임차 계약 시 필요한 서류를 흐름별로 정리
* 출발일 기준 보험기간, 검사유효기간 등 확인 보조
* 추정가격과 계약조건에 따른 추가 확인 서류 안내
* 제출파일에서 서류 후보와 관련 페이지 후보 정리
* 차량번호와 운전자 정보 확인 보조
* 차량별 필수서류 제출 여부 및 검토 포인트 정리
* 담당자가 직접 체크할 수 있는 체크리스트 제공
* 부족 서류에 대한 보완요청 문구 제공
* 직접생산확인증명서의 경우 공공구매종합정보망(SMPP) 조회 링크 제공
* 검토 결과 CSV 내보내기 지원
* 브라우저 기반 처리로 업로드 파일 외부 전송 없음

---
## 🚀 처음 사용하는 방법

1. 출발일을 입력합니다.
2. 추정가격과 계약조건을 필요한 만큼 선택합니다.
3. 업체가 제출한 PDF 또는 이미지 파일을 업로드합니다.
4. 차량번호와 운전자 정보를 확인합니다.
5. `검토요약`, `필요서류 체크리스트`, `차량별 체크` 순서로 확인합니다.
6. 보완이 필요한 항목은 안내 문구를 참고해 업체에 보완 요청합니다.

## 🧭 검토 흐름

버스콕검은 전세버스 임차 서류를 아래 흐름으로 확인할 수 있도록 구성되어 있습니다.

1. 계약조건별 서류
2. 업체 확인 서류
3. 차량 검토 서류
4. 차량별 필수서류

각 서류 항목에서는 다음 내용을 확인할 수 있습니다.

* 이 서류는 어디에 있나요?
* 이 서류에서 뭘 봐야 하나요?
* 담당자는 뭘 하면 되나요?
* 보완이 필요한 경우 어떤 문구로 요청하면 되나요?

## 📌 입력 정보

### 출발일

출발일은 보험기간, 검사유효기간, 출발 전 점검표 확인의 기준이 됩니다.

### 추정가격

추정가격은 선택 입력 항목이지만, 계약조건별 확인 서류 판단에 참고됩니다.

### 차량 정보

배정차량 목록을 입력하거나 제출파일에서 추출된 차량번호를 확인합니다.

차량별 체크에서는 차량번호와 운전자 정보를 기준으로 필수서류 확인 흐름이 정리됩니다.

### 제출파일

업체가 제출한 PDF 또는 이미지 파일을 업로드합니다.

업로드한 파일은 참고용으로 분류되며, 어떤 파일이 어떤 서류 후보에 가까운지 `제출파일 정리` 영역에서 확인할 수 있습니다.

## 📁 확인 서류 범위

### 계약조건별 서류

* 직접생산확인증명서
* 중소기업확인서
* 기타 계약 조건에 따라 필요한 서류

### 업체 확인 서류

* 여객자동차 운송사업등록증
* 사업자등록증
* 직영차량 운행각서

### 차량 검토 서류

* 차량 및 운전기사 배정 현황표
* 차량보유 현황표

### 차량별 필수서류

* 자동차등록원부
* 자동차 종합보험 가입증명서
* 전세버스 교통안전정보 조회결과 통보서
* 출발 전 교육 및 차량안전점검표

---

## 🔎 직접생산확인증명서 확인 안내

직접생산확인증명서는 업체 제출파일에서 확인할 수 있습니다.

제출파일에서 확인되지 않더라도 공공구매종합정보망(SMPP)의 `직접생산확인 조회`에서 업체명 또는 사업자등록번호로 조회 후 증명서를 확인·출력할 수 있습니다.

* 공공구매종합정보망(SMPP) 직접생산확인 조회
  https://www.smpp.go.kr/cop/dpcnfrmn/selectDpCnfrmnListVw.do

## 🏷️ 상태값 안내

| 상태        | 의미                           |
| --------- | ---------------------------- |
| 제출 확인됨    | 제출된 서류에서 해당 내용을 확인할 수 있음     |
| 관련 페이지 있음 | 관련 내용이 있을 가능성이 높은 페이지 후보가 있음 |
| 담당자 확인필요  | 자동 판단이 어려워 담당자가 직접 확인해야 함    |
| 못 찾음      | 제출파일에서 관련 내용을 찾지 못함          |
| 보완 필요     | 제출 또는 확인 보완이 필요함             |

## 🖥️ 화면 구성

### 입력 영역

출발일, 추정가격, 차량정보, 제출파일을 입력하는 영역입니다.

출발일은 필수 확인 기준이며, 추정가격은 계약조건별 확인에 참고됩니다.

### 제출파일 정리

업로드한 파일이 어떤 서류 후보로 분류되었는지 참고용으로 보여줍니다.

파일명, 서류 후보, 관련 페이지 후보를 함께 확인할 수 있습니다.

### 검토요약

전체 제출 상태와 보완 필요 항목을 한눈에 확인할 수 있습니다.

### 필요서류 체크리스트

계약 담당자가 실제로 확인해야 하는 서류를 업무 흐름에 맞게 정리합니다.

### 차량별 체크

차량번호별로 필수서류 제출 여부와 확인해야 할 내용을 정리합니다.

## 🔐 보안 안내

버스콕검은 업로드한 PDF·이미지 파일을 현재 브라우저에서 처리합니다.

파일 내용은 외부 서버로 전송하지 않습니다.

PDF 텍스트 추출이나 이미지 글자 판독을 위해 PDF.js, Tesseract.js 같은 라이브러리를 CDN에서 불러올 수 있습니다.
이는 분석 도구를 불러오는 과정이며, 사용자가 업로드한 파일 내용이 외부로 전송되는 것은 아닙니다.

## ⚠️ 사용 전 확인사항

버스콕검은 전세버스 임차 서류 검토를 돕기 위한 **참고용 보조 도구**입니다.

자동 결과는 최종 적합·부적합 판정이 아니며, 최종 확인과 판단은 담당자가 원본 서류를 기준으로 직접 해야 합니다.

특히 아래 항목은 원본 서류 확인이 필요할 수 있습니다.

* 보험기간
* 검사유효기간
* 실제 배차 차량
* 실제 운전자
* 출발 전 점검 여부
* 교통안전정보 조회결과 통보서의 진위 여부
* 업체 자격 및 계약조건 충족 여부

또한 스캔본, 흐린 이미지, 기울어진 문서, 도장이나 스탬프가 겹친 파일은 자동 추출 정확도가 떨어질 수 있습니다.
