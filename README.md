# 🚌 버스콕검 v0.1.2

전세버스 임차 서류 확인 도구입니다.

배포 예정 페이지: https://sen-vip.github.io/bus-kockgum/

업체가 제출한 서류를 업로드하면 **배정차량 리스트 기준**으로 필수서류, 차량번호, 보험기간, 검사유효기간을 한 번에 확인할 수 있도록 돕습니다.

## 주요 기능

- 출발일 필수 입력 카드 분리
- 선택 정보 영역 정리: 업체명, 행사명, 도착일, 계약방식, 추정가격
- 추정가격 1천만원 이상 여부에 따른 직접생산확인증명서 확인 안내
- 업체 제출 PDF 업로드
- 배정차량 리스트 자동 추출 또는 수동 보정
- 서류별 제출현황 확인
- 배정차량별 보험증명서, 등록원부/등록증, 교통안전정보 통보서 대조
- 보험기간 및 검사유효기간 확인 보조
- 출발 전 확인사항 체크리스트
- 보완요청 문구 자동 생성 및 복사
- 상단 고정바, 섹션 바로가기, 맨위로 버튼 제공

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 출발일을 먼저 입력합니다.
3. 필요한 경우 선택 정보의 업체명, 행사명, 도착일, 계약방식, 추정가격을 입력합니다.
4. 업체가 제출한 PDF 또는 이미지 파일을 업로드합니다.
5. 자동 추출된 배정차량 리스트를 확인하거나 수동 보정합니다.
6. `버스 서류 콕검 시작하기`를 누릅니다.
7. 검토 결과와 보완요청 문구를 확인합니다.

## 확인 가능한 서류

- 차량 및 운전기사 배정 현황
- 차량운행계획서
- 차량보유 현황표
- 여객자동차 운송사업등록증
- 자동차 종합보험 가입증명서
- 직영차량 운행각서
- 자동차 등록원부 또는 자동차등록증
- 전세버스 교통안전정보 조회결과 통보서
- 출발 전 교육 및 차량안전점검표
- 계약조건별 확인서류: 중소기업확인서, 직접생산확인증명서 등

## 배정차량 리스트 기준 확인

버스콕검은 사용자가 차량번호를 처음부터 직접 입력하는 방식이 아닙니다. 업체 제출자료 안의 `차량 및 운전기사 배정 현황`, `차량운행계획서`, `배차현황` 등에서 배정차량을 먼저 찾고, 그 차량번호를 기준으로 다른 서류를 대조합니다.

배정차량 리스트가 없으면 차량별 확인 신뢰도가 떨어지므로 `기준자료 필요` 또는 `기준자료 없음`으로 표시합니다.

## 추정가격 안내

추정가격은 선택 입력이지만, 입력하면 계약조건별 추가서류 확인 안내를 제공합니다.

- 추정가격 1천만원 이상 + 수의계약: `직접생산확인증명서` 확인 필요 안내
- 추정가격 1천만원 이상 + 계약방식 미입력: 계약방식 확인 후 직접생산확인증명서 필요 여부 확인 안내
- 입찰 또는 2인이상 전자견적: 중소기업확인서와 직접생산확인증명서 등 참가자격 확인 안내

## 외부 전송 없음

이 앱은 브라우저에서 실행되는 정적 웹앱입니다. 파일은 서버에 저장하지 않으며, 텍스트 추출 가능한 PDF는 현재 브라우저에서 처리합니다.

단, PDF 텍스트 추출을 위해 CDN의 PDF.js 라이브러리를 불러옵니다. 내부망이나 오프라인 환경에서는 PDF.js 파일을 로컬에 포함하는 방식으로 변경할 수 있습니다.

## 담당자 직접확인 필요 항목

- 교통안전정보 통보서 진위확인
- 실제 배차 차량번호와 서류상 차량번호 일치 여부
- 실제 운전자와 배정 운전자 일치 여부
- 운전자 음주여부 확인
- 차량 내부 소화기, 비상망치, 타이어 상태
- 대열운행 금지 및 안전거리 확보 안내
- 출발 전 안전교육 실시 여부

## 한계

- 텍스트 추출 가능한 PDF 기준으로 작동합니다.
- 이미지 PDF나 스캔본은 OCR 기능이 없으면 자동 인식이 제한됩니다.
- 자동 결과는 행정 검토 보조용이며, 최종 확인은 담당자가 직접 해야 합니다.
